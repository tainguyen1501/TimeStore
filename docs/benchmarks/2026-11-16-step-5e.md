# Step 5e: raw benchmark runs (2026-11-16)

Every warp run of step 5e, unedited. The summary and the decision are in `docs/performance.md` ("Step 5e") and
`docs/research/performance.md` (section 9). warp 1.3.1 (`deploy/bench/warp.sh`), 15 s per workload, a fresh server
and data directory per run. Throughput in obj/s; latencies are per request.

| Config | Meaning | How |
|---|---|---|
| A | Server GC with DATAS, Runtime Async on (defaults) | `timestore:bench` |
| B | Server GC without DATAS | `SERVER_ENV=DOTNET_GCDynamicAdaptationMode=0` |
| C | Workstation GC | `SERVER_ENV=DOTNET_gcServer=0` |
| D | Runtime Async off | image built with `-p:Features=runtime-async=off` |

**Memory column**: rounds 1–2 show `docker stats` in parentheses, which includes the page cache of the written blobs
and is not the server's memory (kept only for completeness); rounds 3–4 have none (a bug in the sampler, fixed
before round 5); round 5 is the server process RSS, the only valid memory number on Linux.
