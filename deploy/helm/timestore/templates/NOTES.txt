Root key pair (S3 access key and admin sign-in):
  kubectl -n {{ .Release.Namespace }} get secret {{ include "timestore.rootSecretName" . }} -o jsonpath='{.data.{{ .Values.rootCredentials.accessKeyKey }}}' | base64 -d; echo
  kubectl -n {{ .Release.Namespace }} get secret {{ include "timestore.rootSecretName" . }} -o jsonpath='{.data.{{ .Values.rootCredentials.secretKeyKey }}}' | base64 -d; echo

S3 API:
{{- if .Values.ingress.s3.enabled }}
  {{ include "timestore.publicUrl" . }}
{{- else }}
  inside the cluster: http://{{ include "timestore.fullname" . }}-s3.{{ .Release.Namespace }}.svc:{{ .Values.service.s3.port }}
  from this machine:  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "timestore.fullname" . }}-s3 9000:{{ .Values.service.s3.port }}
{{- end }}

Admin UI:
{{- if .Values.ingress.admin.enabled }}
  {{ ternary "https" "http" (not (empty .Values.ingress.admin.tlsSecret)) }}://{{ .Values.ingress.admin.host }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "timestore.fullname" . }}-admin 9001:{{ .Values.service.admin.port }}
  then open http://localhost:9001
{{- end }}
{{- if and .Values.ingress.admin.enabled (not .Values.ingress.admin.tlsSecret) }}

WARNING: the admin UI is exposed without TLS: sign-in sends a secret key in clear text. Set ingress.admin.tlsSecret.
{{- end }}

Backups (the server keeps running; docs/backup.md):
  with an access key of role "backup" (admin UI → Access keys), through the admin port:
    curl -fsS --aws-sigv4 "aws:amz:{{ .Values.config.region }}:s3" --user "<key>:<secret>" -OJ http://127.0.0.1:9001/api/v1/backups/stream
{{- if .Values.backup.existingClaim }}
  or POST /api/v1/backups: archives go to the claim {{ .Values.backup.existingClaim }}, folder {{ .Release.Name }}/
{{- end }}
  restore: see the chart README, "Restore a backup"
{{- if .Values.restore.archive }}

restore.archive is set: an empty data volume is filled from it before the server starts (a volume with data is left
alone). Once the server runs on the restored data, remove restore.archive from the values.
{{- end }}
{{- if not .Values.masterKey.existingSecret }}

The master key is kept inside the data volume. For production, create it as a Secret and keep a copy apart from the
data (masterKey.existingSecret, docs/backup.md).
{{- end }}
